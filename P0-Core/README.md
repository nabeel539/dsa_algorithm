# P0 — Core Interview Fundamentals

This directory contains the essential foundation patterns of Data Structures & Algorithms. Mastery of these nine patterns ensures readiness for screening rounds and typical first-round technical interviews at product-based companies.

---

## Suggested Study Order
1. Arrays and Strings $\to$ Hashing (Build frequency and lookup habits)
2. Two Pointers $\to$ Sliding Window (Master contiguous and index optimization)
3. Binary Search $\to$ Sorting (Master order and search boundaries)
4. Stack and Queue $\to$ 2D Arrays $\to$ Basic Recursion
