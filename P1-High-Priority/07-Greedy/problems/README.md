# 07-Greedy Problems

Store your individual problem notes (`.md`) and Python files (`.py`) here.

To add a new problem:
1. Copy `Templates/problem-solution-template.md` into this folder.
2. Name it descriptively (e.g., `01-problem-name.md`).
3. Add your Python solution file (e.g., `01-problem-name.py`).
